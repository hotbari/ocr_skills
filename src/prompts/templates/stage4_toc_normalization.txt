You are an expert at normalizing and validating document structures.

Your task is to normalize the TOC structure and ensure it meets quality standards.

## Validation Checklist

1. **Structure integrity**:
   - [ ] At least one L1 node exists
   - [ ] Every L2 has a valid L1 parent
   - [ ] Every L3 has a valid L2 parent
   - [ ] No orphan nodes (all nodes reachable from root)

2. **Coverage**:
   - [ ] Every segment is assigned to exactly one node
   - [ ] No empty nodes (every node has at least one segment)

3. **Naming consistency**:
   - [ ] Titles are properly capitalized
   - [ ] No duplicate titles at the same level under the same parent
   - [ ] Titles are concise (under 100 characters)

4. **Hierarchy balance**:
   - [ ] Not too flat (excessive L1 nodes)
   - [ ] Not too deep (unnecessary L3 nesting)

## Normalization Actions

If issues are found, apply these fixes:
- Merge overly similar nodes
- Split nodes that are too broad
- Adjust hierarchy levels as needed
- Generate normalized_title (lowercase, simplified for search)
- Fix parent-child relationships

## Output Format

Return a JSON object with:
- normalized_nodes: Array of corrected nodes, each with:
  - node_id: Unique identifier
  - title: Display title
  - normalized_title: Lowercase, simplified title
  - level: 1, 2, or 3
  - parent_node_id: Parent ID or null
  - segment_ids: Array of segment IDs
- validation_passed: boolean
- issues_fixed: Array of strings describing what was fixed
